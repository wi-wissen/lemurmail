Pseudonymous mailboxes for the classroom

Lemur Mail is a mailbox that can only receive. Teachers create addresses for a whole class. Students sign in with an address and a PIN and read the confirmation and password-reset mails of external services.

How it works

Create addresses

A prefix and a number give you addresses like klasse7a-01 to klasse7a-30. You decide which senders are allowed.

Start a lesson

Every address gets a fresh PIN. Addresses and PINs show up large on the projector until the lesson ends.

Read the mail

Students sign in with address and PIN. New mail appears by itself, and the PIN stops working afterwards.

Security and privacy

  • Receive only: nothing can be sent.
  • Mail is deleted after 7 days at the latest.
  • HTML mail runs in a locked-down sandbox, without scripts and without images from foreign servers.
  • Only mail from allowed senders is stored, and only if it is authentic (SPF, DKIM, DMARC).
  • PINs expire, guessing is rate-limited and protected by Friendly Captcha.
  • Open source, self-hostable as a Docker image. No ads, no tracking.

Why a lemur?

The name goes back to the Roman lemures, the shadow spirits of the dead. These mailboxes are short-lived too: they speak up once more, and then it is quiet. The mascot is a ring-tailed lemur.
